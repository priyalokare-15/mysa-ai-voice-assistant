# Mysa – AI Voice Assistant

Mysa is a multilingual AI voice assistant that allows users to interact with AI using their voice and receive helpful responses in their preferred language.

## Features

- Voice input using speech recognition
- AI-powered responses using Google Gemini API
- Multilingual support
- Text-to-speech responses
- Simple and user-friendly interface

## Supported Languages

- English
- Kannada
- Hindi
- Telugu
- Tamil

## Technologies Used

- Java
- Spring Boot
- Google Gemini API
- HTML
- CSS
- JavaScript
- Web Speech API

## How It Works

1. Select your preferred spoken language.
2. Select the language for the AI response.
3. Click the microphone button and ask a question.
4. Mysa processes your question using the Gemini API.
5. The AI response is displayed and spoken aloud.

## Getting Started

### Prerequisites

- Java JDK
- Eclipse IDE or another Java IDE
- Google Gemini API key

### Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/mysa-ai-voice-assistant.git
   ```

2. Open the project in Eclipse.

3. Configure your Gemini API key in `application.properties`:

   ```properties
   gemini.api.key=YOUR_API_KEY
   ```

4. Run the Spring Boot application.

5. Open your browser and visit:

   ```text
   http://localhost:8080
   ```

## Security

Do not share or upload your Gemini API key. Keep it private and out of public repositories.
